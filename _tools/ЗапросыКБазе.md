# Запросы к информационной базе снаружи

Канал, который даёт **читать данные рабочей базы** с любой машины, не выгружая её.
Только чтение: изменить данные языком запросов 1С нельзя в принципе — в нём нет
ни `INSERT`, ни `UPDATE`, ни `DELETE`, а `Запрос.Текст` не выполняет код.

## Как это устроено

```
я  --HTTPS-->  cvetkovtm.com/assets/shop/debug_1c_query.php
                       |  cmd1c(), общий токен
                       v
        tg.cvetkovtm.com:8443/tgbot/hs/tg/hook   (HTTPСервис.ТелеграмВебхук)
                       |  action = query | meta
                       v
             ОбщийМодуль.ЧтениеДанныхБазы
```

Напрямую в базу с моей машины не постучаться: firewall на машине с 1С пускает на 8443
только подсети Telegram и исходящий адрес хостинга сайта. Поэтому спрашивает сайт,
а я читаю его пересказ. Тот же адрес и тот же токен, которыми сайт уже пишет в базу
номера накладных, — новой дырки наружу не появилось.

| | |
|---|---|
| Точка входа | `https://cvetkovtm.com/assets/shop/debug_1c_query.php?token=e4cfdff6ad370ca2f0e26d8eb82bcda9` |
| Файл на сайте | `../modx/shop/debug_1c_query.php` |
| Код в 1С | `CommonModules/ЧтениеДанныхБазы/Ext/Module.bsl`, вход — `HTTPServices/ТелеграмВебхук` |
| Журнал | событие **«База.Запрос»**, каждый запрос: текст, число строк, время |

## Параметры

| | |
|---|---|
| `q` | текст запроса. Пакет через `;` разрешён, в ответ идёт последний запрос с колонками |
| `meta` | `Документ.ЗаказПокупателя` — поля, табличные части, движения; `*` — список объектов |
| `like` | подстрока для отбора при `meta=*` (по имени и синониму) |
| `limit` | строк в ответе, 1..5000, по умолчанию 500 |
| `ids` | `1` — к ссылкам добавить идентификатор и таблицу (чтобы ходить по ним дальше) |
| `full` | `1` — не резать длинные значения до 60 символов |
| `format` | `table` (по умолчанию), `csv`, `json` |
| `params` | JSON с параметрами запроса, см. ниже |
| `timeout` | секунд на ответ 1С, по умолчанию 60, максимум 280 |

Длинный запрос слать **POST**-ом: кириллица в GET доезжает, но URL становится нечитаемым.

```
curl -s --data-urlencode "token=…" \
        --data-urlencode "q=ВЫБРАТЬ ПЕРВЫЕ 20 Ссылка, Наименование ИЗ Справочник.Склады" \
        https://cvetkovtm.com/assets/shop/debug_1c_query.php
```

## Параметры запроса

Скаляры пишутся как есть, типы, которых в JSON нет, — структурой с полем `type`:

```json
{
  "НачалоПериода": {"type": "дата",   "value": "2026-08-01"},
  "Номенклатура":  {"type": "ссылка", "table": "Справочник.Номенклатура", "id": "e1c2…"},
  "Статус":        {"type": "ссылка", "table": "Перечисление.СтатусыЗаказов", "value": "ВРаботе"},
  "Склады":        [{"type": "ссылка", "table": "Справочник.Склады", "id": "…"}]
}
```

Массив годится для `В (&Список)`. Даты чаще проще написать прямо в тексте —
`ДАТАВРЕМЯ(2026, 8, 1)`, — и параметры тогда не нужны вовсе.

## С чего начинать разбор

Имена таблиц и полей спрашивать у базы, а не угадывать по XML выгрузки:

```
&meta=*&like=заказ                     какие объекты вообще есть
&meta=Документ.ЗаказПокупателя         поля, табличные части, по каким регистрам двигает
&meta=Перечисление.СтатусыЗаказов      значения перечисления (в базе их нет, только в метаданных)
```

`movements` в ответе по документу — самый короткий ответ на вопрос
«где искать последствия этого документа».

## Ограничения, о которых надо помнить

* **Общего числа строк ответ не содержит.** Считать их — значит прочитать всю выборку;
  нужно количество — спрашивать `КОЛИЧЕСТВО(*)` отдельным запросом. `truncated` в ответе
  означает только «упёрлись в limit».
* **Оборвать запущенный запрос нечем.** Платформа не даёт, поэтому тяжёлый запрос
  честно займёт рабочий процесс до конца, а сайт отвалится по своему таймауту.
  Соединения и джойны по большим регистрам сначала ограничивать периодом.
* **Ссылки отдаются представлением** — это обращение к объекту на каждое значение (N+1).
  На пятистах строках заметно. Если представление не нужно, выбирать не ссылку,
  а `Ссылка.Код` / `Ссылка.Наименование` или ставить `ids=1` и читать идентификаторы.
* **`КОЛИЧЕСТВО(*)` по виртуальной таблице `.Остатки(...)` возвращает 1.** Проверено
  18.08.2026 на `РасчетыСКонтрагентами.Остатки`: `СУММА(...)` в той же строке считается
  верно, а счётчик врёт. Считать `КОЛИЧЕСТВО(РАЗЛИЧНЫЕ <измерение>)` — на том же запросе
  вместо 1 получилось 12 665.
* **Адрес длиннее ~2000 символов `WebFetch` не берёт** — отвечает `Invalid URL`, до сайта
  запрос не доходит. Кириллица в `q` раздувается в шесть раз, поэтому длинный запрос
  сокращать псевдонимами или разбивать на несколько.
* **Однобуквенный псевдоним `В` ломает разбор** — платформа читает его как оператор `В`
  и отвечает «Ожидается имя». Не использовать также `И`, `ИЗ`, `КАК`.
* **Двоичное не отдаётся** — хранилища значений и картинки приходят как `<двоичные данные>`.
* Ответ идёт через кеширующий nginx, поэтому скрипт ставит `no-store`. Если вдруг видно
  старый ответ — добавить к адресу `&u=<любое новое число>`.

## Изменение справочников

Отдельный адрес и отдельный модуль (`ОбщийМодуль.ИзменениеСправочников`), чтобы читалка
осталась читалкой:

```
https://cvetkovtm.com/assets/shop/edit_1c_catalog.php?token=<тот же токен>
   &catalog=Справочник.Склады
   &items=[{"code":"000000055","set":{"Наименование":"Склад Барабошово"}}]
```

| | |
|---|---|
| `catalog` | `Справочник.Склады` или просто `Склады` |
| `items` | JSON-массив, не больше 200 строк |
| `apply` | `1` — записать. **Без него не пишется ничего**, показывается «было → станет» |
| `format` | `json` — отдать ответ 1С как есть |

Строка `items` адресует элемент одним из способов и говорит, что с ним делать:

```json
{"id":   "e1c2…",         "set": {"Наименование": "Склад Болото"}}
{"code": "000000055",     "set": {"Активный": false}}
{"name": "Абсолютно все", "mark": true}
{"new":  true,            "set": {"Наименование": "Новый склад"}}
```

Ссылочные реквизиты задаются так же, как параметры запроса:
`{"type": "ссылка", "table": "Справочник.Склады", "id": "…"}`.

Чего канал не делает намеренно: документы, регистры, константы и физическое удаление.
Строку длиннее реквизита **не пишет, а отказывается** — платформа усекает такое молча.
Тёзки по `name` отклоняются, а не угадываются. Каждый вызов, включая проверку, пишется
в журнал регистрации, событие **«База.Запись»**.

## Если не отвечает

| Ответ | Что это |
|---|---|
| `нет связи с 1С: …timeout` | база не видна: выключен сервер, упал IIS-сайт `tg1c`, сменился исходящий IP хостинга (его нужно вписать в правило firewall «Telegram webhook 1C (8443)») |
| `токен не принят 1С` | `ТелеграмБот.ТокенСайта()` в базе разошёлся с константой в `inc_1c_cmd.php` |
| `403` от самого скрипта | не тот `token=` в адресе |
| синтаксическая ошибка запроса | приходит текстом из 1С как есть — это нормально, канал служебный |

Проверка связи, не трогая данные: `shop/debug_1c_log.php?token=…&ping1c=1`.
