Звіт "Оборотно-Сальдова відомість (бухгалтерська)"

Звіт містить для кожного рахунку інформацію про залишки на початок і на кінець періоду й оборотах по дебету й кредиті за період.

Настройка звіту

Відомість може бути побудована за даними бухгалтерського обліку обраної організації

По кнопці «Сформувати» виконується побудова звіту відповідно до поточної настройки

Кнопка «Заголовок» дозволяє одержати більше компактний вид звіту, приховуючи його заголовок

Кнопки збереження й відновлення значень дозволяють зберігати користувальницькі настройки звіту, щоб використовувати їх надалі.

Форма настройки звіту (відкривається по кнопці «Настройка») дозволяє задавати всі можливі параметри звіту, у т.ч. і ті, які задаються на головній формі. Форма містить наступні закладки:

Загальні

  • Дати початку й кінця періоду звіту
  • Організація, за даними обліку якої будується відомість
  • «Розгорнуте сальдо» - якщо прапорець встановлений, початкове й кінцеве сальдо по певних рахунках будуть виведені в розгорнутому виді. Список цих рахунків і правила розрахунку розгорнутого сальдо по них задається на закладці «Розгорнуте сальдо».
  • «Деталізація по субрахунках і субконто» - коли прапорець вимкнено,в звіт виводяться тільки сальдо й обороти по рахунках верхнього рівня. Якщо ж прапорець встановлений, у звіт також будуть виведені дані й по субрахунках, а для певних рахунків - дані по субконто. Список рахунків, що детализуються по субконто й порядок субконто задається на закладці
  • «Дані по валютах» - якщо прапорець встановлений, для валютних рахунків будуть виводитися валютні суми
  • «Дані по забалансових рахунках» - якщо прапорець встановлений, в звіт будуть виведені не тільки балансові, але й забалансові рахунки. Обороти й сальдо по забалансових рахунках не включаються в загальний підсумок звіту

 Деталізація

На закладці настроюються правила деталізації окремих рахунків. У кожному рядку вказується правило деталізації одного рахунку

  • Вибирається рахунок, для якого задається правило
  • У колонку «По субрахунках» може бути встановлена ознака деталізації по субрахунках
  • У колонку «По субконто» може бути заданий список видів субконто, по яких потрібно деталізувати рахунок
  • Розгорнуте сальдо.
  • На закладці настроюються правила розрахунку розгорнутого сальдо для обраних рахунків. У кожному рядку вказується правило для одного рахунку
  • Вибирається рахунок, для якого задається правило
    • В колонці «По субрахунках» може бути встановлена ознака розвороту сальдо по субрахунках
    • В колонці  «По субконто» може бути заданий список видів субконто, по яких потрібно розвертати сальдо по рахунку
      Сальдо може бути розгорнуто або по субрахунках, або по субконто.

Розшифровка

Рядки звіту із залишками й оборотами по рахунках можуть бути розшифровані оборотно-сальдовою відомістю по рахунку або карткою рахунку
