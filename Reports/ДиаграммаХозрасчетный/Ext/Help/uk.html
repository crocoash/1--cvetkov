Звіт "Діаграма"

 Звіт призначений для подання даних бухгалтерських даних по окремих рахунках в графічному виді

Настроювання звіту

Діаграма може бути побудована по обраному рахунку бухгалтерського обліку для обраної організації

По кнопці «Сформувати» виконується побудова звіту відповідно до поточного настроювання

Кнопки збереження й відновлення значень дозволяють зберігати користувальницькі настроювання звіту, щоб використовувати їх надалі.

Форма настроювання звіту (відкривається по кнопці «Настроювання») дозволяє задавати всі можливі параметри звіту, у т.ч. і ті, які задаються на головній формі.

Закладка "Загальне"

Містить основні параметри:

  • Дати початку й кінця періоду звіту
  • Рахунок. Вказується аналізований рахунок
  • Організація За даними бухгалтерського обліку цієї організації будується звіт
  • Період Періодичність подання даних (по днях, тижнях, декадах, місяцям і т.д.)
  • Вид підсумків Вид даних, які необхідно представити в графічному виді: залишки або обороти по рахунку, дебет або кредит, суму або кількість

Закладка "Серії й точки"

Містить параметри джерела даних для діаграми:

  • Серії Дані, які утворять серії при побудові діаграми. Для кожного виду серії може бути зазначений вид висновку даних: елементи, ієрархія або тільки ієрархія
  • Точки Дані, які утворять окремі точки для серії діаграми. Для кожного виду точьок може бути зазначений вид видображення даних: елементи, ієрархія або тільки ієрархія
  • Максимум серій Визначає режим обмеження максимальної кількості відображуваних серій діаграми. Даний параметр визначає кількість серій, що буде відображено в діаграмі:
    • Немає. Будуть відбиті всі серії
    • Кількість Буде відбита тільки задана кількість серій з максимальним значенням. Дані серій, що залишилися, підсумуються й виводяться у зведеній серії
    • Відсоток від максимального Будуть відображені тільки ті серії, максимум яких, перевищує поріг від абсолютного максимуму даних, що відповідають настроюванню. Дані серій, що залишилися, підсумуються й виводяться у зведеній серії

Закладка "Діаграма"

Містить параметри відображення діаграми:

  • Тип діаграми
  • Вид підписів Визначаються параметри підписів, використовувані для пояснення значення кожної точки діаграми
  • Розсування Визначає параметри розсування секторів для кругових діаграм. Може висуватися сектор з максимальним або мінімальним значенням, можуть розсовуватися всі сектори
  • Так само задається виведення окантовки, відображення заголовка, відображення легенди, відображення світла (моделювання ефекту освітленості об'ємних діаграм).

Закладка "Відбір"

Відбір даних діаграми. В кожному рядку задається один елемент відбору, що містить:

  • Прапорець використання елемента відбору. Дозволяє легко відключати й включати окремі елементи відбору без видалення й додавання елементів
  • Поле, на значення якого накладаються умови відбору
  • Вид порівняння - умова відбору.
  • Значення або значення для порівняння.

Для умов відбору на входження в інтервал задається двома значеннями - границями інтервалу. Якщо накладається умова на входження в список, значення порівняння задаються списком значень
