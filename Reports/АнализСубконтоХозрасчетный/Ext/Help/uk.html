Звіт "Аналіз субконто (бухгалтерський)"

Звіт виводить початкове й кінцеве сальдо й обороти за період по рахунках, що має обрані субконто.

Настройки звіту

Аналіз може бути побудований по обраним субконто, використовуваним в бухгалтерському обліку для обраної організації. На основній формі звіту можлива настройка для першого субконто, настройка для інших субконто можна задати на формі настройкия звіту

По кнопці «Сформувати» виконується побудова звіту відповідно до поточної настройки

Кнопка «Заголовок» дозволяє одержати більш компактний вид звіту, приховуючи його заголовок

Кнопки збереження й відновлення значень дозволяють зберігати користувальницькі настройки звіту, щоб використовувати їх вдальнейшем.

Форма настройки звіту (відкривається по кнопці «Настройка») дозволяє задавати всі можливі параметри звіту, у т.ч. і ті, які задаються на головній формі.

Закладка "Загальні"

Містить основні параметри :

  • Дати початку й кінця періоду звіту
  • Субконто 1, Субконто 2, Субконто 3. Вказуються види субконто й значення субконто, по яких будуть відібрані й деталізовані дані бухгалтерського обліку. Якщо обрано вид субконто, у звіт потраплять рахунку, що мають субконто даного виду, при цьому рядка звіту будуть згруповані за значеннями даного субконто. Якщо крім виду субконто обране значення субконто, то воно буде використаний як фільтр
  • Організація За даними бухгалтерського обліку цієї організації будується звіт
  • По субрахунках Коли прапорець встановлений, у звіт додатково будуть виведені підсумки  по субрахунках.
  • Дані по валютах Якщо прапорець встановлений, для валютного рахунку будуть виводитися валютні суми
  • Дані по кількості. Якщо прапорець встановлений, для кількісного рахунку буде виводитися кількість

Закладка "Відбір"

Відбір даних звіту. У кожному рядку задається один елемент відбору, що містить:

  • Прапорець використання елемента відбору. Дозволяє легко відключати й включати окремі елементи відбору без видалення й додавання елементів
  • Поле, на значення якого накладаються умови відбору
  • Вид порівняння - умова відбору.
  • Значення або значення для порівняння.

Для умов відбору на входження в інтервал задається двома значеннями - границями інтервалу. Якщо накладається умова на входження в список, значення порівняння задаються списком значень

Розшифровка

Рядка звіту із сальдо й оборотом по рахунках за період можуть бути розшифровані карткою рахунку, а рядка деталізації по субконто - журналом проводок
