Звіт "Шахова відомість"

Звіт містить табличне подання оборотів між рахунками за деякий обраний період по заданій організації. Рядки таблиці відповідають рахункам за дебетом, стовпці - рахункам за кредитом. 

Настройка звіту

Відомість може бути побудована за даними бухгалтерського обліку обраної організації

По кнопці «Сформувати» виконується побудова звіту відповідно до поточної настройки

Кнопка «Заголовок» дозволяє одержати більше компактний вид звіту, приховуючи заголовок відомості

Кнопки збереження й відновлення значень дозволяють зберігати користувальницькі настройки звіту, щоб використовувати їх вдальнейшем.

Прапорці на формі задають додаткові настройки деталізації відображуваних даних:

  • По валютах Якщо прапорець встановлений, будуть виводитися дані по кожній валюті для валютних рахунків
  • По субрахунках Якщо прапорець встановлений, будуть виводитися дані по субрахунках
  • Дані по забалансовим рахункам Якщо прапорець встановлений, будуть виводитися дані не тільки по балансових рахунках, але й по забалансовим

Розшифровка

Рядки звіту із залишками й оборотами по рахунках можуть бути розшифровані "Звітом по проведках".
