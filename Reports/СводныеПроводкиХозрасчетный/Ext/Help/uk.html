Звіт "Зведені проводки"

Звіт містить обороти між рахунками за деякий обраний період по заданій організації

Настройка звіту

Відомість може бути побудована за даними бухгалтерського обліку обраної організації

По кнопці "Сформувати" виконується побудова звіту відповідно до поточної настройки

Кнопка "Заголовок" дозволяє одержати більш компактний вид звіту, приховуючи заголовок відомості

Кнопки збереження й відновлення значень дозволяють зберігати користувальницькі настройки звіту, щоб використовувати їх надалі.

Форма настройки звіту (відкривається по кнопці "Настройка") дозволяє задавати всі можливі параметри звіту, у т.ч. і ті, які задаються на головній формі

  • Дати початку й кінця періоду звіту

  • Організація, за даними бухгалтерського обліку якої будується відомість
  • По субрахунках Якщо прапорець встановлений, будуть виводитися дані по субрахунках, а не тільки по рахунках першого рівня
  • Впорядкування. Задається порядок впорядкування виведених даних: по дебетових рахунках або по кредитових рахунках
  • Відбір по валюті Для відображення зведених проводок тільки по одній валюті може бути встановлений відбір по необхідній валюті

Розшифровка

Рядки звіту із залишками й оборотами по рахунках можуть бути розшифровані "Звітом по проводках".
