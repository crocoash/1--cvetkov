Звіт "Аналіз субконто (податковий облік)"

Звіт виводить початкове й кінцеве сальдо й обороти за період по рахунках, що мають обрані субконто.

Настройка звіту

Аналіз може бути побудований по обраним субконто, використовуваним в податковому обліку для обраної організації. На основній формі звіту знаходиться настройка для першого субконто, настройки для інших субконто можна задати на формі настройки звіту

По кнопці «Сформувати» виконується побудова звіту відповідно до поточної настройки

Кнопка «Заголовок» дозволяє одержати більш компактний вид звіту, приховуючи його заголовок

Кнопки збереження й відновлення значень дозволяють зберігати користувальницькі настройки звіту, щоб використовувати їх надалі.

Форма настройки звіту (відкривається по кнопці «Настройки») дозволяє задавати всі можливі параметри звіту, у т.ч. і ті, які задаються на головній формі.

Закладка "Загальні"

Містить основні параметри :

  • Дати початку й кінця періоду звіту
  • Субконто 1, Субконто 2, Субконто 3. Вказуються види субконто й значення субконто, по яких будуть відібрані й деталізовані дані податкового обліку. Якщо обрано вид субконто, у звіт потраплять рахунки, що мають субконто даного виду, при цьому рядки звіту будуть згруповані за значеннями даного субконто. Якщо крім виду субконто обране значення субконто, то воно буде використане як фільтр
  • Організація По даним податкового обліку цієї організації будується звіт
  • По субрахунках Коли прапорець встановлений, у звіт додатково будуть виведені підсумки  по субрахунках.
  • Дані по валютах Якщо прапорець встановлений, для валютного рахунку будуть виводитися валютні суми
  • Дані по кількості. Якщо прапорець встановлений, для кількісного рахунку буде виводитися кількість

Закладка "Відбір"

Відбір даних звіту. В кожному рядку задається один елемент відбору, що містить:

  • Прапорець використання елемента відбору. Дозволяє легко відключати й включати окремі елементи відбору без видалення й додавання елементів
  • Поле, на значення якого накладаються умови відбору
  • Вид порівняння - умова відбору.
  • Значення або значення для порівняння.

Для умов відбору на входження в інтервал задається двома значеннями - границями інтервалу. Якщо накладається умова на входження в список, значення порівняння задаються списком значень

Розшифровка

Рядки звіту із сальдо й оборотом по рахунках за період можуть бути розшифровані карткою рахунку, а рядка деталізації по субконто - звітом по проводках.
