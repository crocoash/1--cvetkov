Форма звіту

Угорі звіту в центрі розташована панель варіантів звіту. На ній відображаються кнопки вибору варіанта звіту, доступні поточному користувачеві. Поточна (обрана) кнопка варіанта звіту має контекстне меню, що збігається з діями кнопки "Змінити варіант". При наведенні миші на кнопку варіанта з'являється підказка - опис варіанта звіту.

Праворуч угорі на формі розташовуються кнопки: "Список варіантів" - використовується для вибору варіанта звіту зі списку, для зміни Найменування, Опису й складу користувачів варіанта звіту, "Зберегти" - містить два пункти - "Зберегти" - зберігає поточний варіант звіту, якщо користувач має право змінювати зі збереженням або викликається дія "Зберегти як..." у противному випадку, "Зберегти як.." - користувачеві пропонується ввести назву нового варіанта звіту або зберегти поточний варіант під іншим варіантом. При цьому користувачеві доступно для збереження як інший варіант тільки ті варіанти, які він має право змінювати зі збереженням. При створенні нового варіанта в списку користувачів звіту створюється поточний користувач із ознакою права зміни.

Поруч із кнопкою "Сформувати" розташовуються три кнопки: "Друк відразу" - висновок відразу на принтер, "Дії з результатом", "Виводити заголовок звіту" - чи відображати заголовок звіту. "Дії з результатом" містить наступні пункти: "Вивести сформований звіт у табличний документ", "Зберегти сформований звіт для порівняння" і "Зрівняти сформований звіт зі збереженим". Збереження поточного сформованого звіту відбувається для кожної пари Користувач - Варіант звіту

Праворуч у звіті розташовується панель користувача. Всі настроювання панелі користувача зберігаються автоматично для кожного користувача.
