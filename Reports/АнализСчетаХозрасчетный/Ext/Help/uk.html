Звіт "Аналіз рахунку (бухгалтерський)"

Звіт виводить початкове й кінцеве сальдо по рахунку обліку, а також обороти в кореспонденції з рахунками. Додатково можна одержати деталізацію по субрахунках і субконто, а також вивести проміжні підсумки з певною періодичністю

Настройка звіту

Аналіз може бути побудований по обраному рахунку бухгалтерського обліку для обраної організації

По кнопці «Сформувати» виконується побудова звіту відповідно до поточної настройки

Кнопка «Заголовок» дозволяє одержати більш компактний вид звіту, приховуючи його заголовок

Кнопки збереження й відновлення значень дозволяють зберігати користувальницькі настройки звіту, щоб використовувати їх надалі.

Форма настройки звіту (відкривається по кнопці «Настройки») дозволяє задавати всі можливі параметри звіту, у т.ч. і ті, які задаються на головній формі.

Закладка "Загальні"

Містить основні параметри :

  • Дати початку й кінця періоду звіту
  • Рахунок. Вказується аналізований рахунок
  • Організація За даними бухгалтерського обліку цієї організації будується звіт
  • Показувати обороти. Зі списку можна вибрати періодичність, з якої будуть виводитися проміжні підсумки
  • По кор. субрахунках і субконто. Коли прапорець встановлений, обороти з кореспондуючими рахунками будуть додатково деталізуватися по субрахунках, і по субконто, якщо на закладці "Деталізація кор. рахунків" настроєна деталізація рахунку по субконто.
  • Дані по валютах Якщо прапорець встановлений, для валютного рахунку будуть виводитися валютні суми
  • Дані по кількості. Якщо прапорець встановлений, для кількісного рахунку буде виводитися кількість

Закладка "Деталізація рахунку"

Задаються правила деталізації аналізованого рахунку

  • По субрахунках Ознака деталізації рахунку по субрахунках
  • По субконто. У списку задаються види субконто, по яких потрібно деталізувати рахунок

Закладка "Деталізація кор. рахунків"

Тут можна задати правила деталізації кор. рахунків по субконто. Ці правила починають працювати після установки прапорця "По кор. субрахунках і субконто" на першій закладці. Таблиця має стовпчики

  • рахунок, для якого задається правило розвороту;
  • прапорець розвороту рахунку по субрахунках;
  • субконто, по яких буде розгорнутий рахунок

Закладка "Відбір"

Відбір даних звіту. У кожному рядку задається один елемент відбору, що містить:

  • Прапорець використання елемента відбору. Дозволяє легко відключати й включати окремі елементи відбору без видалення й додавання елементів
  • Поле, на значення якого накладаються умови відбору
  • Вид порівняння - умова відбору.
  • Значення або значення для порівняння.

Для умов відбору на входження в інтервал задається двома значеннями - границями інтервалу. Якщо накладається умова на входження в список, значення порівняння задаються списком значень

Розшифровка

Рядка звіту, що містять обороти з кореспондирующими рахунками, можуть бути розшифровані журналом проводок, а рядка із сальдо й оборотом за період можуть бути розшифровані карткою рахунку
