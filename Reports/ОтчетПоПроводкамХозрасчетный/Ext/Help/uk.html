Звіт "Звіт по проводках (бухгалтерський облік)"

Звіт призначений для одержання списку проводок по заданих критеріях

Настройка звіту

Звіт може бути побудований по обраним критеріям для обраної організації

По кнопці "Сформувати" виконується побудова звіту відповідно до поточної настройки

Кнопка "Заголовок" дозволяє одержати більш компактний вид звіту, приховуючи його заголовок

Кнопки збереження й відновлення значень дозволяють зберігати користувальницькі настройки звіту, щоб використовувати їх надалі.

Форма настройка звіту (відкривається по кнопці "Настройка") дозволяє задавати всі можливі параметри звіту, у т.ч. і ті, які задаються на головній формі. Форма містить наступні закладки:

Закладка "Загальне"

У даній закладці задаються наступні параметри:

  • Дати початку й закінчення звітного періоду

  • Організація Найменування організації, для бухгалтерського обліку якої формується  звіт

  • Кореспонденції Зазначення списку кореспонденцій для відбору проводок. В таблиці кореспонденцій вказується список кореспонденцій рахунків, які необхідно відібрати у звіт. Наприклад:

    • Дт 90, Кт 28 - будуть відібрані проводки, рахунок дебету яких входить в групу рахунку 90, а рахунок кредиту в групу рахунку 28

    • Дт 702 - будуть відібрані проводки, в яких рахунок дебету дорівнює 702, рахунок кредиту може бути будь-яким

    • Якщо не зазначений жоден рахунок, то будуть відібрані всі проводки

  • Для кожної зазначеної кореспонденції можуть бути зазначені додаткові відбори по аналітиці:

    • Прапорець використання елемента відбору. Дозволяє легко відключати й включати окремі елементи відбору без видалення й додавання елементів

    • Поле, на значення якого накладаються умови відбору

    • Вид порівняння - умова відбору.

    • Значення або значення для порівняння

      Закладка "Відбір"

      На даній закладці вказуються правила відбору, що ставляться до всіх кореспонденцій відразу:

      • Валюта Відбирати проводки тільки по певній валюті
      • Номер журналу Відбирати проводки, що входять тільки в зазначений журнал
      • Документ Відбирати проводки тільки одного документа
      • Підрядок. Настройка відбору проводки по підрядку. Пошук  може здійснюватися як в змісті проводки (прапорець "В змісті"), так і в поданні субконто (прапорець "В субконто"). Прапорець "Без урахування регістра" відключає врахування регістра при пошуку підрядка

      Розшифровка

      При розшифровці рядка звіту відкривається документ, що породив дану проводку
