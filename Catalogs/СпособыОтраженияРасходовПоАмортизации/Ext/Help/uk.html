Довідник "Способи відображення витрат по амортизації"

Довідник містить способи віднесення витрат по амортизації основних засобів і нематеріальних активів на витрати підприємства в бухгалтерському обліку. У довіднику вказуються способи одержання бази для розподілу амортизації, рахунки й аналітика для віднесення на витрати

Перелік способів задається в табличній частині "Способи". Кожний рядок табличної частини визначає сукупність параметрів для віднесення видатвів з амортизації на витрати. В тому випадку якщо уведено кілька рядків, витрати з амортизації спочатку будуть розподілені по рядках (способам) відповідно до коефіцієнтів розподілу. Коефіцієнти розподілу вказуються в кожному рядку. У випадку якщо в табличній частині зазначений тільки один рядок (тобто заданий тільки один спосіб), коефіцієнт варто встановлювати рівним одиниці

Для основних засобів спосіб відображення витрат по амортизації може бути встановлений в документах: "Введення в експлуатацію ОЗ", "Зміна способів відображення витрат по амортизації". Для нематеріальних активів - в документах "Прийняття до обліку НМА", "Зміна способу відображення витрат по амортизації НМА ".
