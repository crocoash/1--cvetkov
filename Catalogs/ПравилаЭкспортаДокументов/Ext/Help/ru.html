В поле Документ выбирается документ из списка документов, существующих в конфигурации.

Первая табличная часть - Правила - заполняется реквизитами ТТН и источниками значений или самими значениями их заполнения:

-В колонке Реквизит ТТН указывается один из элементов справочника Реквизиты ТТН. 

-В колонке Реквизит документа указывается один из реквизитов выбранного документа. При формировании ТТН в качестве значения реквизита ТТН будет взято значение указанного реквизита документа (Например: Реквизиту ТТН "Отправитель" можно назначить соответствие реквизита документа "Организация" или "Организация.Наименование").

-Колонки Выражение и Выражения представления позволяют ввести програмный код для определения значения (имя переменной "Значение") и представления значения (имя переменной "Значение") реквизита ТТН (Например: Реквизиту ТТН "Город отправителя" в качестве выражения можно указать "Значение = "Киев";", а в качестве выражения представления "Значение="г. "+Строка(Значение);"). К реквизитам документа можно обратиться через конструкцию "ВходящиеДанные.ДокументСсылка". (Например: Реквизиту ТТН "Объявленная стоимость" в качестве выражения можно указать "СуммаТоваровПоДокументу = ВходящиеДанные.ДокументСсылка.Товары.Итог("Сумма");Значение = Формат(СуммаТоваровПоДокументу,"ЧДЦ=2; ЧГ=0");"). 

-Колонка Проверять заполнение позволяет указать значение каких Реквизитов ТТН обязательны к проверке перед отправкой. Кроме того независимо от настройки Правил для конкретного документа, проверка заполнения будет производиться для реквизитов ТТН, у которых установлен признак "Обязательный". 

Вторая табличная часть - Объекты пользовательских настроек - позволяет указать настройки каких объектов будут использоваться при формировании ТТН, позиция в списке определяет приоритет настройки выбранного объекта (первый в списке объект имеет выше приоритет чем второй и т.д.). Так указав для реквизита ТТН "Отправитель" в табличной части Правила соорветствие реквизита документа "Организация.Наименование" и выбрав пользовательскую настройку Организация, первостепенно будет проверено наличие пользовательской настройки для самого документа (ссылка - объект пользовательской настройки наиболее приоритетный, устанавливается по умолчанию), потом наличие пользовательской настройки для выбранной в документе организации, и только если вышеуказанные пользовательские настройки найдены не будут, будет получено значение исходя из правил, указанных в табличной части Правила. Колонка Тип объекта в табличной части заполняется автоматически.
