Довідник "Призначення використання"

Довідник призначений для оприділення призначень використання переданих в експлуатацію малоцінних активів

Заповнення реквізитів

  • Найменування - довільний текст. Найменування призначення використання
  • Вид малоцінки - до якої категорії  буде відноситися актив по призначенню використання:
    • Малоцінний швидкозношуваний предмет;
    • Малоцінний необоротний актив;
    • Бібліотечний фонд
  • Кількість по нормативі видачі - кількість по нормативу. Значення реквізиту використовується для підстановки за замовчуванням кількості в документи.
  • Одиниця - одиниця виміру кількості (базова одиниця виміру номенклатури, власника даного призначення)
  • Строк корисного використання - строк корисного використання малоцінного активу.
  • Спосіб відображеняя витрат - спосіб відображення в витратах суми погашеної вартості малоцінного активу
  • Рахунок передачі - рахунок бухгалтерського обліку по призначенню використання (рахунок на якому буде значитися актив після передачі в експлуатацію). Для МШП - "222", оскільки саме з цього рахунку вони списуються на витрати в сумовому еквіваленті, а на цей рахунок спишеться кількість переданого матеріалу. Для малоцінних необоротних активів і бібліотечних фондів були заведені спеціальні субрахунки з аналітикою по номенклатурі й кількісному обліку ("1122"," 1112"). Ці рахунки підставляються за замовчуванням, при зміні виду матеріалу
  • Рахунок амортизації - рахунок бухгалтерського обліку амортизації по призначенню використання. На цьому рахунку буде значитися амортизація, нарахована після передачі в експлуатацію малоцінних нематеріальних активів і бібліотечних фондів
