Обработка «Выгрузка данных в весы Off-Line»

При помощи обработки «Выгрузка данных в весы Off-Line» производится загрузка информации о весовых товарах в электронные весы , работающие в режиме Off-Line, для проведения взвешивания и этикетирования весового товара. Работа с данной обработкой доступна только в том случае, если в списке торгового оборудования присутствуют физически подключенные электронные весы в режиме «Off-line».

Внимание. В электронные весы выгружаются только те товары, у которых в позиции номенклатуры установлен признак «Весовой» и на закладке «Штрихкоды» определены коды весового товара.

Чтобы заполнить список загружаемых весовых товаров пользователю необходимо выполнить следующие действия:

  1. Указать модель электронных весов, в которые нужно загрузить товары.
  2. Установить тип цен, по которому должны быть установлены цены для загружаемых товаров.
  3. Нажать кнопку «Заполнить» — список загрузки будет автоматически заполнен весовыми товарами.

Кнопка «Выгрузить в весы» предназначена для загрузки сформированного списка в электронные весы для проведения взвешивания и этикетирования товаров.

При выгрузке можно произвести отбор по группе номенклатуры или по конкретным номенклатурным позициям. Если необходимо выгрузить информацию только по тем товарам, которые имеются в наличии, необходимо установить  флажок «Только имеющиеся в наличии» и указать склад или список складов, на которых будет контролироваться остаток весовых товаров. Если склады не указаны, то контроль количества весового товара производится по всем складам.
