Обробка "Заповнення малоцінки по залишкам"

Обробка призначена для заповнення табличних частин  "Малоцінні активи" документів. Вона викликається з форми документа по натисканню кнопки "Заповнити по залишкам".  Обробка зчитує залишки по рахунку МЦ "Малоцінні активи в експлуатації" і заповнює ними табличну частину документа.  Для зчитування залишків можливо використовувати відбір

Відбір

 В кожному рядку задається один елемент відбору, що містить:

  • Прапорець використання елемента відбору. Дозволяє легко відключати й включати окремі елементи відбору без видалення й додавання елементів
  • Поле, на значення якого накладаються умови відбору
  • Вид порівняння - умова відбору.
  • Значення або значення для порівняння. Для умов відбору на входження в інтервал задається двома значеннями - границями інтервалу. Якщо накладається умова на входження в список, значення порівняння задаються списком значень
