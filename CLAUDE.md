# Правила работы с этой конфигурацией

Рабочая папка — полная файловая выгрузка 1С «Управление торговым предприятием для Украины» 1.2
(платформа 8.3.25.1374). Доставка правок: я правлю файлы → пользователь делает «Загрузить
конфигурацию из файлов» → F7 (обновление конфигурации БД).

## Штрихкоды в макетах — проверять ВСЕГДА перед сдачей работы

Штрихкод в печатных формах — не картинка, а **ActiveX-объект** внутри макета
(`<drawing><drawingType>Object</drawingType>` с блобом `<object xsi:type="xs:base64Binary">`
в `Template.xml`). «Выгрузка конфигурации в файлы» выборочно теряет этот блоб и/или имя рисунка
(`namedItem`), а обратная загрузка сносит объект и в базе. Пользователь видит это как
«пропали картинки/фото в макетах» — на месте штрихкода пустая рамка.

**Мой обязательный порядок (не пользователя — мой):**

```
1. Пользователь выгрузил конфигурацию в файлы / я закончил задачу
2. powershell -NoProfile -File _tools\fix-barcodes.ps1 -Применить
3. powershell -NoProfile -File _tools\check-barcodes.ps1
4. Отдавать работу и предлагать заливку в базу ТОЛЬКО после
   «Все внедрённые объекты на месте»; результат писать в ответе
```

Прогонять **при сдаче любой задачи** и **после каждой перевыгрузки пользователем**, без напоминания.
Само оно не восстанавливается: без шага 2 штрихкоды сносит при каждой заливке.

Подробный разбор (два класса компоненты V8.Barcod.1/.2, ложные следы, грабли PowerShell) —
[_tools/ШтрихкодыВМакетах.md](_tools/ШтрихкодыВМакетах.md), лежит здесь же в репозитории.

## Коммитить всегда

Каждую законченную задачу и каждую новую выгрузку фиксировать снимком, не дожидаясь просьбы:

```
powershell -NoProfile -File _tools\snapshot.ps1 "что сделано"
```

`snapshot.ps1` сам прогоняет fix→check штрихкодов, потом делает `git add -A` + коммит. То есть
шаги 2–3 выше выполняются им автоматически — отдельно их гонять нужно только вне снимка.
Коммит — это ещё и контрольная точка: если пользователь уйдёт в Конфигуратор и выгрузит поверх
папки, незалитые в базу правки тихо откатятся, и вернуть их можно только `git checkout` от снимка.

## Прочее по этой папке

- Линт: `powershell -File _tools\lint.ps1 [подпапка]` (BSL Language Server, jar в git не хранится).
- `.ps1` с кириллицей сохранять **в UTF-8 с BOM**, иначе PowerShell 5.1 ломается на разборе.
- `Template.xml` писать только UTF-8 с BOM; строки продолжения base64 — с нулевой позиции строки
  (любой лишний отступ → «Ошибка формата потока» при загрузке).
