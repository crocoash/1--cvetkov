Документ «Зміна графіків амортизації ОЗ»

Документ "Зміна графіків амортизації ОЗ" використовується для зміни річного графіку амортизації по основним засобам, для яких при нарахуванні амортизації використовується лінійний спосіб

Об'єкти, по яких встановлюється графік амортизації, вибираються з довідника "Основні засоби".
Для більш швидкого заповнення табличної частини документа  необхідно скористатися кнопкою "Підбір".

При проведенні документа ці відомості записуються в регістр і використовуються документом "Закриття місяця" при нарахуванні амортизації в місяці, наступному  за місяцем зміни графіку розподілу амортизації

Даний документ не формує ніяких проводок, він лише змінює значення відповідних ресурсів регістра відомостей ("Графіки амортизації бухгалтерський облік").

Для зміни інших характеристик обліку основних засобів (наприклад - способу відображення витрат по амортизації, графіків нарахування амортизації та ін.) використовуються інші документи - "Зміна параметрів нарахування амортизації ОС", "Зміна способів відображення витрат по амортизації" ...

Для швидкого заповнення табличної частини однотипними об'єктами основних засобів, що мають однакові найменування, потрібно ввести в табличну частину хоча б один такий об'єкт. Потім треба скористатися кнопкою Заповнити у командній панелі табличної частини. При виборі в меню, що випадає, пункту По найменуванню таблична частина буде заповнена об'єктами основних засобів, що мають таке ж найменування, як і в введеного спочатку.
