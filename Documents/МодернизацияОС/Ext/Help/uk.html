Документ "Модернізація ОЗ"

Документ "Модернізація ОЗ" призначений для відображення в обліку модернізації (реконструкції) основних засобів для цілей бухгалтерського і податкового обліку.

У шапці документа вносяться відомості про об'єкти будівництва, з якого списуються витрати по модернізації, для бухгалтерського і податкового обліку - рахунок обліку витрат, а так само суми модернізації, окремо для кожного з видів обліку

Суму модернізації можна одержати автоматично - при натисканні кнопки "Розрахувати суми" суми модернізації заповняться автоматично за даними обліку на момент формування документа. При необхідності ці суми можна відкоригувати вручну.

В табличній частині "Основні засоби" вказуються об'єкти основних засобів, які модернізуються (реконструюються).

Для більш швидкого заповнення табличної частини документа  необхідно скористатися кнопкою "Підбір".

Після формування списку основних засобів необхідно скористатися кнопкою "Заповнити" для заповнення табличної частини  інформацією про об'єкти основних засобів за даними обліку, що існує на момент введення документа а також для розподілу сум модернізації

Для швидкого заповнення табличної частини однотипними об'єктами основних засобів, що мають однакові найменування, потрібно ввести в табличну частину хоча б один такий об'єкт. Потім треба скористатися кнопкою Заповнити у командній панелі табличної частини. При виборі в меню, що випадає, пункту По найменуванню таблична частина буде заповнена об'єктами основних засобів, що мають таке ж найменування, як і  в введеного спочатку.

При автоматичному заповненні суми модернізації розподіляються рівними частками по всіх об'єктах, перерахованим у табличної частини

Якщо модернізуються (реконструюються) об'єкти, для яких амортизація нараховується пропорційно випущеної продукції (робіт, послуг), те необхідно вказати загальний обсяг випуску продукції (робіт, послуг) з урахуванням модернізації  (реконструкції) об'єктів

При проведенні документа ці відомості записуються в регістр і використовуються документом "Закриття Місяця" при нарахуванні амортизації в місяці, наступному за місяцем відображення модернізації
