Документ "Списання ОЗ"

Документ «Списання ОЗ» призначений для відображення в обліку вибуття основних засобів у зв'язку з моральним і фізичним зношуванням, а також при ліквідації у зв'язку з надзвичайною ситуацією:

  • в бухгалтерському обліку;
  • в податковому обліку

об'єкти, що вибувають, вибираються з довідника "Основні засоби".

Для кожного об'єкта основних засобів вказується поточна балансова вартість, сума накопиченої на початок місяця амортизації, розрахункова сума амортизації, що повинна бути донарахована за поточний місяць

Для більш швидкого заповнення табличної частини документа  необхідно скористатися кнопкою "Підбір".

Після формування списку основних засобів, підготовлюваних до передачі необхідно скористатися кнопкою "Заповнити" для заповнення табличної частини  інформацією про об'єкти основних засобів за даними обліку, сума амортизації за поточний місяць визначається розрахунковим шляхом в документі

Для швидкого заповнення табличної частини однотипними об'єктами основних засобів, що мають однакові найменування, потрібно ввести в табличну частину хоча б один такий об'єкт. Потім треба скористатися кнопкою Заповнити у командній панелі табличної частини. При виборі в меню, що випадає, пункту По найменуванню таблична частина буде заповнена об'єктами основних засобів, що мають таке ж найменування, як і в введеного спочатку.

Відображення в бухгалтерському обліку

При списанні основних засобів необхідно оформити акт про списання об'єкта основних засобів. Для цього варто нажати на кнопку "ОЗ-3".

При списанні з обліку кожного з перелічених в табличній частині основних засобів для об'єктів, формуються проводки:

 по донарахуванню амортизації, якщо це необхідно;
 по списанню амортизаційних нарахувань;
 по списанню залишкової вартості об'єкта на зазначений у формі рахунок обліку витрат. 

Додатково в регістрах відомостей знімається прапорець нарахування амортизації по перерахованим в документі об'єктам обліку

Донарахована амортизація розподіляється по витратах, аналогічно документу "Закриття місяця".

В податковому обліку списання основних засобів відображається відповідно до податкового законодавства

В якості рахунку обліку витрат при списанні основних засобів по бухгалтерському обліку за замовчуванням пропонується рахунок 976 "Списання необоротних активів". 

Якщо ліквідація відбувається за рішенням платника податків, а не в слідство руйнування, то для коректування ПДВ можна ввести на підставі даного документа податкову накладну
