Документ "Реєстрація вхідного податкового документу"

Документ призначений для реєстрації первинних документів, що є підставами для внесення записів в реєстр податкових накладних. Кожний документ «Реєстрація вхідного податкового документу» відповідає одному рядку в реєстрі.

Помітимо, що записи в  реєстрі податкових накладних про операції з імпорту реєструються документами  «ВМД по імпорту».
