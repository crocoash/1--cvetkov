Документ "Регистрация входящего налогового документа"

Документ предназначен для регистрации первичных документов, являющихся основаниями для внесения записей в реестр налоговых накладных. Каждый документ «Регистрация входящего налогового документа» соответствует одной строке в реестре.

Заметим, что записи в реестре налоговых накладных об операциях по импорту регистрируются документами  «ГТД по импорту».
