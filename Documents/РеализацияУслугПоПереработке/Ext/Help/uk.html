Документ "Реалізація послуг з переробки"

Документ призначений для відображення в бухгалтерському й податковому обліку операції надання послуг з випуску продукції з давальницької сировини і відображення звіту про використані при випуску продукції давальницькі матеріали

Загальні реквізити документа

  • Контрагент  Замовник переробки сировини. Значення реквізиту вибирається з довідника "Контрагенти". Реквізит є обов'язковим для заповнення.

  • Договір  Договір з замовником переробки сировини, що має вид "З покупцем".

  • Закладка "Продукція (послуги з переробки)"

    На закладці вказується продукція з давальницької сировини, послуги, по випуску яких оформлюється даний документ

    • Номенклатура. Випущена продукція з давальницької сировини за вартістю послуг по її виробництву. Значення реквізиту вибирається з довідника "Номенклатура" і є обов'язковим для заповнення

    • Специфікація. Специфікація продукції, якщо для даної продукції заведена специфікація. Значення реквізиту вибирається з довідника "Специфікації номенклатури". Така інформація дозволить автоматично розрахувати склад матеріалів, необхідний для виробництва зазначеної продукції, заповнити закладку "Матеріали замовника".

    • Зміст послуги Додаткова інформація про виконану послугу.  

    • Кількість Кількість випущеної продукції
    • Ціна Ціна реалізації послуги з випуску продукції
    • Сума Сума реалізації послуги з випуску продукції.
    • Вартість (планова). Планова ціна (в валюті регламентированого обліку) продукції, виробленої із сировини замовника
    • Сума (планова). Планова вартість (в валюті регламентированого обліку) продукції, виробленої із сировини замовника
    • Рахунок  (БО). Рахунок бухгалтерського обліку виробництва продукції з давальницької сировини (наприклад, 234). Значення реквізиту вибирається з плану рахунків бухгалтерського обліку і заповнюється автоматично при виборі продукції на підставі даних регістра відомостей "Рахунки обліку номенклатури".
    • Схема реалізації. Схема реалізації послуги. Значення заповнюється автоматично при виборі продукції на підставі даних регістра відомостей "Рахунки обліку номенклатури".

    Передбачене заповнення даної табличної частини по кнопці "Заповнити". Заповнення провадиться по звіту виробництва за зміну, що буде вибраний із запропонованого списку й в якому рахунок обліку готової продукції буде 234 або по залишкам рахунку 234.

    Закладка "Матеріали замовника"

    На закладці вказуються матеріали, прийняті в переробку, які були використані при випуску продукції

    • Номенклатура. Матеріал, прийнятий у переробку. Значення реквізиту вибирається з довідника "Номенклатура" і є обов'язковим для заповнення

    • Кількість Кількість матеріалу
    • Рахунок (БО). Рахунок бухгалтерського обліку матеріалу, прийнятого в переробку й переданого у виробництво (наприклад, 0222). Значення реквізиту вибирається з плану рахунків бухгалтерського обліку.

    Передбачене заповнення даної табличної частини по кнопці "Заповнити". Заповнення провадиться давальницькими матеріалами, які були передані у виробництво і враховані на рахунку 0222 "Матеріали, передані у виробництво" або склад матеріалів можна розрахувати по специфікаціях і продукції, зазначеним на закладці "Продукція й послуги".

    Закладка "Рахунки розрахунків"

    На закладці в документі заповнюються «Рахунок розрахунків з контрагентом» і «Рахунок розрахунків по авансах». Ці рахунки заповнюються відповідно до заданого в регістрі відомостей «Контрагенти» значеннями за замовчуванням для кожного контрагента. При необхідності користувач може змінити кореспонденцію рахунків

    Особливості проведення документа

    За даними табличної частини "Продукціяі і послуги" відображається реалізація послуг з переробки за плановими цінами й списання готової продукції, вирбленої з матеріалів замовника з рахунку 234 за плановими цінами.

    За даними табличної частини "Матеріали замовника" відображається списання матеріалів замовника з рахунку 0222, як використаних на виробництво продукції для замовника, звіт по яких прийнятий замовником
