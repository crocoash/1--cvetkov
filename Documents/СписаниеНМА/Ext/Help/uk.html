Документ "Списання НМА"

Документ «Списання НМА» призначений для відображення в обліку вибуття нематеріального активу, в зв'язку із припиненням його використання

Документ відображається по:

  • бухгалтерському обліку;
  • податковому обліку

об'єкти, що вибувають, вибираються з довідника "Нематеріальні активи".

Для кожного об'єкта НМА вказується поточна балансова вартість, сума накопиченої на початок місяця амортизації, розрахункова сума амортизації, що повинна бути донарахована за поточний місяць

Для більш швидкого заповнення табличної частини документа  необхідно скористатися кнопкою "Підбір".

Після формування списку активів, підготовлюваних до списання необхідно скористатися кнопкою "Заповнити" для заповнення табличної частини  інформацією про нематеріальні активи за даними обліку, сума амортизації за поточний місяць визначається розрахунковим шляхом в документі

Відображення в бухгалтерському обліку

При списанні з обліку кожного з перелічених в табличній частині нематеріального активу, формуються проводки:

 по донарахуванню амортизації, якщо це необхідно;
 по списанню амортизаційних нарахувань і балансовой вартості
 по списанню залишкової вартості НМА на зазначений у формі рахунок обліку витрат. 

Додатково в регістрах відомостей відзначається стан по перерахованим у документі об'єктам обліку

В якості рахунку обліку витрат при списанні нематеріальних активів по бухгалтерському обліку за замовчуванням пропонується рахунок 976 "Списання необоротних активів". 

 

Нарахування амортизації відображається в бухгалтерському й податковому обліку
