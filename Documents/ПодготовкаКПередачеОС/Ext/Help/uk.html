Документ "Підготовка до передачі ОЗ"

Документ "Підготовка до передачі ОЗ" використовується якщо угода по передачі основних засобів підлягає державній реєстрації

Об'єкти, що вибувають, вибираються з довідника "Основні засоби".
Для кожного об'єкта основних засобів вказується поточна балансова вартість, сума накопиченої на початок місяця амортизації, розрахункова сума амортизації, що повинна бути донарахована за поточний місяць

Для більш швидкого заповнення табличної частини документа  необхідно скористатися кнопкою "Підбір".

Після формування списку основних засобів, підготовлюваних до передачі необхідно скористатися кнопкою "Заповнити" для заповнення табличної частини  інформацією про об'єкти основних засобів за даними обліку, сума амортизації за поточний місяць визначається розрахунковим шляхом в документі

При проведенні документа по кожному рядку будуть сформовані проводки в бухгалтерському та податковому обліку (якщо в документі зазначено, що він відображається в цих видах обліку):
 по донарахуванню амортизації, якщо це необхідно;
 по списанню амортизаційних нарахувань та балансової вартості

Додатково в регістрах відомостей знімається прапорець нарахування амортизації по вкразаним в документі об'єктам обліку.

Донарахована амортизація розподіляється по регістрах обліку витрат, аналогічно документу "Закриття місяця".

Після того, як необхідні реєстраційні документи одержуючою стороною отримані, необхідно ввести документ "Передача ОЗ".

Для швидкого заповнення табличної частини однотипними об'єктами основних засобів, що мають однакові найменування, потрібно ввести в табличну частину хоча б один такий об'єкт. Потім треба скористатися кнопкою Заповнити в командної панелі табличної частини. При виборі в меню, що випадає, пункту По найменуванню таблична частина буде заповнена об'єктами основних засобів, що мають таке ж найменування, як і в введеного спочатку.
