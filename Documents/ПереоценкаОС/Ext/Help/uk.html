Документ "Зміна параметрів нарахування амортизації"

Документ «Зміна параметрів нарахування амортизації» призначений для відображення змін у регістрі відомостей про об'єкти основних засобів для цілей бухгалтерського і податкового обліку.

У документ вносяться нові відомості про об'єкти основних засобів (наприклад, новий строк корисного використання у випадку його зміни, вартість для нарахування амортизації або обсяг продукції(робіт) і т.п.).

Для більш швидкого заповнення табличної частини документа  необхідно скористатися кнопкою "Підбір".

Після формування списку основних засобів, що підлягають зміні параметрів необхідно скористатися кнопкою "Заповнити" для заповнення табличної частини  інформацією про об'єкти основних засобів за даними обліку, що існує на момент введення документа

Для швидкого заповнення табличної частини однотипними об'єктами основних засобів, що мають однакові найменування, потрібно ввести в табличну частину хоча б один такий об'єкт. Потім треба скористатися кнопкою Заповнити у командній панелі табличної частини. При виборі в меню, що випадає, пункту По найменуванню таблична частина буде заповнена об'єктами основних засобів, що мають таке ж найменування, як в введеного спочатку.

При проведенні документа ці відомості записуються в регістр і використовуються документом "Закриття місяця" при нарахуванні амортизації в місяці, наступному за місяцем зміни параметрів

Даний документ не формує ніяких проводок, він лише змінює значення відповідних ресурсів регістрів відомостей, що зберігають інформацію про основні засоби

Для зміни інших характеристик обліку основних засобів (наприклад - способу відображення витрат з амортизації, графіків нарахування амортизації та ін.) використовуються інші документи - "Зміна графіків амортизації ОЗ", "Зміна способів відображення витрат з амортизації" ...
