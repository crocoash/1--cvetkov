Документ "Партія"

Допоміжний документ, що не робить ніяких проведок, призначений для ведення ручного обліку по партіях, тобто для організації субконто "Партія" на рахунках бухгалтерського обліку

Реквізити необхідні для заповнення:

  • Організація
  • Контрагент - постачальник партії товарів або матеріалів;
  • Договір - договір поставки партії товарів або матеріалів;
