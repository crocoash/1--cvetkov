Документ "Розрахунковий документ"

Допоміжний документ, що не робить ніяких проводок, призначений для ведення ручного обліку по розрахункових документах, тобто для організації субконто "Документи розрахунків з контрагентами" на рахунках розрахунків з контрагентами. Реквізити необхідні для заповнення:

  • Організація
  • Контрагент
  • Договір
