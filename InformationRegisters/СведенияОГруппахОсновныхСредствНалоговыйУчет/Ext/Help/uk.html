Регістр відомостей "Відомості про групи основних засобів податковий облік".

В даному регістрі по кожнійій з податкових груп зберігаються відомості, використовувані для нарахування амортизації основних засобів в податковому обліку

Виміром є податкова група ОЗ, характеристики якої зберігають ресурси:

  • Пооб'єктно  - коли ця ознака встановлена, конфігурація буде зберігати балансову вартість для кожного основного засобу в цій групі, якщо ж ознаку зняти, то балансова вартість буде зберігатися цілком для всієї групи. 
  • Стаття амортизації  - стаття податкової декларації, по якій буде списуватися амортизація об'єктів, що належать групі
  • Стаття списання вартості - стаття податкової декларації, по якій буде списуватися залишкова вартість групи або об'єкта групи в оприділенних законодавством випадках
  • Мінімальна вартість об'єкта -  балансова вартість основного засобу, по досягненні якої основний засіб повинен бути списаний з податкового обліку повністю.
