Регістр відомостей "Облікова політика (податковий облік)"

Призначений для зберігання відомостей про облікову політику організації для цілей оподатковування

Періодичний (період - місяць, що дорівнює мінімальному податковому періоду по ПДВ).

В регістр вводяться наступні відомості про облікову політику для оподатковування:

  • Схема оподатковування використовується для обліку податку на прибуток підприємства з метою наступного коректного формування декларації з податку на прибуток
  • Спосіб оцінки МВЗ (спосіб розрахунку собівартості МВЗ: ФІФО або по середній вартості) - для ведення податкового обліку з податку на прибуток і ПДВ;
