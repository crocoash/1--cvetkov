Регістр відомостей "Способи відображення витрат по амортизації основних засобів (бухгалтерський облік)"

В регістрі зберігаються дані про  способи відображення витрат по амортизації для основних засобів організацій для бухгалтерського обліку

Дані з регістра використовуються при розрахунку амортизації

Регістр періодичний, змінюється документами:

  • "Введення початкових залишків ОЗ";
  • "Зміна способів відображення витрат по амортизації ОЗ";
  • "Введення в эксплуатцию ОЗ".
