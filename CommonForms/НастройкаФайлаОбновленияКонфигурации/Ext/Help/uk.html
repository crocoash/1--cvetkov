Форма "Настроювання файлу оновлення конфігурації"

За допомогою цієї форми можна настроїти формування bat-файлу автоматичного оновлення конфігурації для вузлів розподіленої інформаційної бази

Форма призначена для редагування константи "Настроювання файлу оновлення конфігурації". Константа використовується механізмом автоматичного обміну даними

 При обміні даними між вузлами розподіленої інформаційної бази даних можливий випадок, коли файл обміну містить інформацію про зміну метаданних конфігурації. Для внесення змін в інформаційну базу з такого файлу можна застосувати такий спосіб. Після читання з файлу закрити програму, запустити конфігуратор, прийняти зміни метаданих які були внесені, знову завантажити програму й виконати повторне читання даних (при першому читанні даних автоматично неможливо застосувати всі зміни для поточної інформаційної бази, тому що файл обміну містить інформацію про зміну метаданих).

Для автоматизації такого процесу й існує дане настроювання. Після проведення обміну даними може бути створений bat-файл що виконуює наступні дії:

1. Завершення роботи всіх користувачів із програмою (виконується під логіном адміністратора інформаційної бази)

2. Запуск конфігуратора й застосування всіх змін (виконується під логіном адміністратора інформаційної бази)

3. Дозвіл роботи користувачам із програмою (виконується під логіном адміністратора інформаційної бази)

4. Запуск програми під користувачем, під яким виконувався обмін даними

 Існує 2 варіанти настроювання такого bat-файлу:

1. Настроювання з наступним автоматичним формуванням bat-файлу

2. Настроювання зі збереженням тексту bat-файлу

 При настроюванні bat-файлу, текст якого буде сгенерирован автоматично при роботі програми є наступні настроювання:

1. Адміністратор інформаційної бази даних - логін адміністратора інформаційної бази даних

2. Ім'я файлу для запису помилок - файл, у який будуть записуватися всі помилки й повідомлення при зміні конфігурації інформаційної бази

 При настроюванні зі збереженням тексту bat-файлу необхідно вказати повний текст bat-файл, що повинний створюватися для оновлення конфігурації

 Після виконання настроювання є можливість подивитися сам bat-файл, що буде створюватися при застосуванні змін кконфигурации.

Виконати дії по автоматичній зміні конфігурації можна у формі "Виконання обміну даними" при натисканні на кнопку "Застосувати зміни конфігурації"
